# P6 Предрегистрация: сравнение с реальными данными (v3)

**Статус:** утверждена (v2). v3 — дополнения при реализации.
**Дата фиксации:** до загрузки данных.
**Изменения v3:** RT-критерий слабый (записано), подгруппы для разброса,
правила нормализации accuracy, алгоритм разметки сна зафиксирован,
Zou недоступен, Brolsma проверен.
**Изменения v2:** пороги из данных (не произвольные), MLE для DDM,
распределения вместо бинарных порогов, уверенность в «не производит»,
среда RL адаптируется под протокол, циркулярный критерий убран.

## Общие правила

1. Критерии зафиксированы до загрузки данных и не меняются после.
2. Расхождение — результат, не повод для настройки (правило 7).
3. Оцениваются только fitted-параметры. Exploratory и untested на калиброванных.
4. Наблюдаемые из «не воспроизводит» исключены.
5. **Нет бинарных порогов.** Отчёт — доля прошедших с CI и распределение ошибок.

## Сравнение 1: DDM — Confidence Database

### Набор данных

Confidence Database. OSF: https://osf.io/s46pr/.
Rahnev et al. (2020), Nature Human Behaviour, DOI: 10.1038/s41562-019-0813-1.

### Критерии отбора (механические)

1. Задача: двухальтернативный (2AFC).
2. Модальность: перцептивная.
3. RT: trial-level время реакции обязательно.
4. RT > 0.1 с и RT < 5 с (стандартная очистка).
5. Минимум 200 проб на участника (для MLE).

**Нет требования на число уровней трудности.** Многие наборы в базе имеют
постоянную трудность внутри условия. Подход работает с одним уровнем.

### Подзадача шага 0: проверка выживаемости

**До утверждения:** скачать метаданные (readme-файлы) Confidence Database,
применить критерии 1–5, посчитать сколько наборов осталось. Если < 10 —
пересмотреть критерии или масштаб сравнения. Доложить.

### Наблюдаемые для сравнения

| Наблюдаемая | Сравнивается | Обоснование |
|-------------|:------------:|-------------|
| Accuracy (по условиям) | **да** | DDM воспроизводит |
| Mean RT (по условиям) | **да** | DDM воспроизводит |
| RT quantile profile | **нет** | Не воспроизводит (D16, нет eta) |
| Right-skew pattern | **нет** | Не воспроизводит (D16) |

**Confidence:** база содержит шкалу уверенности почти во всех наборах.
У платформы нет модуля метапознания. Это готовая наблюдаемая категории
«модель не производит» — записывается явно.

| Параметр | Класс | Действие |

| a (threshold) | fitted | Оценивается |

### Метод оценки: MLE по RT-распределению

Замкнутая процедура моментов (из Roitman) непригодна для индивидуальных
данных: при 30 пробах на уровень три параметра из 3–4 шумных точек. Вместо
этого — **maximum likelihood** по аналитическому распределению RT первого
пересечения (формула Навальника—Фелмли или быстрая аппроксимация Navarro &
Fuss 2009). Стандартная процедура для индивидуальной подгонки DDM.

Если MLE нереализуема в срок — fallback: **метод моментов на агрегате**
внутри набора (не на участнике). Тогда сравнение — групповое, не
индивидуальное. Это оговаривается.

### Пороги согласия: из межнаборного разброса

**Вычислены из данных до подгонки (72 набора).**

SD по средним наборов = 0.047 — занижен: средние сжимают разброс
между уровнями трудности. Пересчитано по сопоставимым уровням:

| Подвыборка | Accuracy SD | Примечание |
|------------|:-----------:|------------|
| Single-condition (22) | **0.038** | Однородная трудность |
| Multi, easiest (47) | **0.100** | Потолочные accuracy |
| Multi, hardest (47) | **0.257** | Включает chance и ниже |
| Multi, per-dataset mean (50) | 0.050 | Сжатый, не используется |

**Три порога по категориям (зафиксированы до подгонки):**

| Категория | Accuracy SD | Порог (1×SD) | Качество |
|-----------|:-----------:|:------------:|----------|
| Single-condition (22) | 0.038 | ±0.038 | Содержательный |
| Multi, easiest level (47) | 0.100 | ±0.100 | Умеренный |
| Multi, hardest level (47) | 0.257 | ±0.257 | **Малоинформативный** |

Единого порога не существует: разброс между категориями в семь раз.
При общем пороге на трудных уровнях пройдёт что угодно, на лёгких
модель провалится незаслуженно.

**Hardest SD=0.257 — ограничение данных.** Это почти весь диапазон
между случайным уровнем (0.50) и потолком (1.00). Наборы расходятся
между собой настолько, что сравнение на трудных уровнях
малоинформативно. Записано, не пересмотрено.

RT: SD = 0.535 с (51%). **Слабый** (записано).

**Ревизия постфактум (по образцу D17).** Исходный критерий (1×SD
по средним наборов = 0.047) оказался дефектным: средние по наборам
сжимают разброс между уровнями трудности. Замена на три порога
обоснована (неоднородность), но сделана после подсчёта разброса,
а не до. Это ревизия, не уточнение. Зафиксирована как D45.

Процедура вычисления:
1. Для каждого набора, прошедшего отбор, вычислить accuracy и mean RT.
2. Посчитать межнаборный разброс (SD) по accuracy и mean RT на сопоставимых
   уровнях трудности.
3. Порог согласия = 1 × межнаборный SD. Модель должна попадать в
   диапазон, в котором находятся сами наборы.
4. Вычисление — до подгонки модели (только из эмпирических данных).

**Слабость RT-критерия (записано до подсчёта).** При пилотном SD(RT)=0.56 с
и среднем 1.06 с, допуск = ±53%. Причина: наборы различаются задачами и
аппаратурой (от 0.47 до 2.44 с) сильнее, чем модель отклоняется от каждого.
Критерий по RT слабый. Не пересматриваем, но интерпретируем.

**Подгруппы для разброса (объявлены до подсчёта).**
Разброс вычисляется отдельно для однородных подгрупп:
- Зрительные 2AFC с двухкнопочным откликом (самая распространённая).
- Все перцептивные 2AFC (полная выборка).
Отчёт включает оба разброса. Если подгрупповой SD < полного, подгрупповой
более информативен.

**Нормализация accuracy.** Правила преобразования фиксируются в файле
`data/accuracy_coding.json` до расчёта метрик:
- Для каждого набора: какие значения Stimulus/Response означают «верно».
- Источник: readme файл набора.
- Наборы с неустановимым кодированием исключаются с указанием причины.

**Отчёт:** доля наборов в пороге с CI. Распределение ошибок.
Раздельно: многоусловные (57) и одноусловные (44). Не бинарный вердикт.

### Ожидаемое расхождение

DDM без eta: слишком узкие RT-распределения при низкой трудности. На людях
резче, чем на обезьянах (D16). Подтверждение методологии, не провал.

## Сравнение 2: Arousal — OBF-Psychiatric

### Набор данных

OBF-Psychiatric. Zenodo: https://zenodo.org/records/13754984.
DOI: 10.1038/s41597-025-04384-3. CC BY 4.0.
162 человека, 1565 дней актиграфии.

### Критерии отбора

1. Только контроль (здоровые).
2. >= 5 суток записи на участника.
3. Сон — из актиграфии (Cole-Kripke или аннотации если есть).

### Наблюдаемые

| Наблюдаемая | Сравнивается | Обоснование |
|-------------|:------------:|-------------|
| Распределение длительности сна | **да** | Модель калибрована |
| Распределение момента засыпания | **да** | Круговая статистика |
| Число переходов | **нет** | Нет посекундной разметки |
| Onset advance | **нет** | INDETERMINATE (D13) |

### Параметры

Все exploratory. Подгонка невозможна. Только групповое сравнение:
распределение модели (B=200 реплик) vs распределение данных.

### Критерии согласия: перекрытие распределений

1. **Длительность сна:** среднее модели попадает в IQR данных.
   Дополнительно: коэффициент перекрытия (overlap coefficient)
   распределений модели и данных.
2. **Момент засыпания:** круговое среднее модели vs круговое среднее
   данных. Разность в единицах кругового SD данных.

**Отчёт:** распределения рядом (модель vs данные), overlap coefficient,
разность средних в единицах SD. Не бинарный вердикт.

### Алгоритм разметки сна (зафиксирован до применения)

**Основной:** порог по средней активности. Окно 11 минут (±5 мин), медианная
фильтрация. Порог: минута считается сном, если средняя активность в окне < T.
T = percentile(activity, 15) — адаптивный, вычисляется по записи каждого
участника. Минимальная длительность эпизода сна: 30 мин.

**Контрольный (правило 14):** Cole-Kripke rescoring. Пересчёт вывода при
смене алгоритма. Если выводы различаются: записывается как зависимость от
метода, а не как один результат.

### Модель не воспроизводит (P6 результат)

| Наблюдаемая | Данные | Модель | Причина |
|-------------|:------:|:------:|---------|
| Свободноживущая вариабельность | within-SD 2.50h, onset 92 мин | 0.50h, 21.5 мин | **Структурное:** модель не содержит внешних источников (социальное расписание, выходные, кофеин, экраны). Никакое σ_h не воспроизведёт правильным механизмом |

D18 (onset circ SD = 21.5 мин, Klerman & Dijk lab) не проверен: лабораторные
vs свободноживущие — разные условия. Предсказание проверяемо на лабораторных
данных актиграфии; на OBF-Psychiatric не тестируется.

### Ограничения

- Групповое сравнение. Одна точка в пространстве параметров vs выборка.
- Актиграфия != полисомнография. Алгоритм разметки влияет (десятки минут).
- Phillips-Robinson: нет NREM/REM структуры.
- Within-individual SD (2.50h) > between (0.66h): индивидуальная подгонка
  по нескольким ночам малоосмысленна даже при восстановимых параметрах.
- Systematic exclusion: 3 subjects undetected by alg1 had mean sleep
  9.97h (alg2) vs 7.75h for included. Not random (permutation p=0.0015).
  Not length-of-recording bias (12–14 days, within range). Cause:
  alg1 adaptive threshold (80th pct nighttime activity) fails on
  subjects with high baseline nocturnal activity — who happen to be
  long sleepers. Excluding them pulls alg2 intersection mean down
  by 0.20h, contributing to model falling on CI boundary.

## Сравнение 3: RL — Eckstein et al. 2022

### Замена набора (D44)

Zou et al. (2022) — файлы на OSF пусты (0 bytes). Заменён первоисточником
протокола: Eckstein, Master, Dahl, Wilbrecht & Collins (2022).

### Набор данных

Eckstein et al. (2022), Dev Cogn Neurosci 55:101106.
OSF: https://osf.io/7wuh4/ (trial-level) + https://osf.io/h4qr6/ (сводки).
291 участник, 8–30 лет. Здоровые. CC-By 4.0.

### Протокол Eckstein vs ReversalBandit

Протокол Eckstein (из методов статьи):
- 2AFC (selected_box 0/1) — совпадает.
- p_reward correct = **0.75** — совпадает.
- p_reward incorrect = **0.00** (никогда не вознаграждается).
  У нас: 1−p_reward = 0.25. **Несовместимо.**
- Реверсия: по **критерию** (7–15 собранных вознаграждений,
  число рандомизировано по блокам). Не по вероятности на пробу.
  У нас: Geom(volatility/20) на каждой пробе. **Несовместимо.**
- Переключение только после rewarded trial. Нет у нас.
- 120 проб (не 131 — разница вероятно tutorial).

**Три несовместимости:**
1. Реверсия по критерию vs по вероятности. У Eckstein длина блока
   зависит от поведения участника. У нас — стохастическая.
2. Incorrect = 0% vs 25%. Информативность ошибок разная.
3. Реверсия только после reward. Структурное ограничение.

**Следствие:** ReversalBandit в текущем виде не представляет протокол
Eckstein. Адаптация среды (правка 6 спецификации) потребовала бы:
новый класс среды CriterionReversalBandit или значительное расширение
ReversalBandit. Это за пределами P6.

**Решение:** среда адаптирована. ReversalBandit получил режим `criterion`:
- `reversal_mode='criterion'`: реверсия после criterion_range[0]...[1]
  собранных rewards, только после rewarded trial.
- `p_incorrect=0.0`: incorrect arm никогда не вознаграждается.
- `criterion_range=(7, 15)`: из методов Eckstein.

Сравнение выполняется на адаптированной среде. Модуль (RL+Mood) не
трогается — меняется среда. Контракт сохранён (стимул → выбор → reward).
Тесты E11–E15: block length, p_incorrect=0, reversal-only-after-reward,
reward rate, backward compatibility.

### Два режима среды ReversalBandit

| Режим | Протокол | Реверсии | p_incorrect | Применяется |
|-------|----------|----------|-------------|-------------|
| `geom` | Behrens 2007 | Geom(volatility/20) | 1−p_reward | Калибровка P2.4, все P3/P4 |
| `criterion` | Eckstein 2022 | После 7–15 rewards | 0.0 | Сравнение P6 RL |

Калибровка (α=0.15, β=2.50) сделана на geom. Сравнение с Eckstein — на
criterion. Это не перекалибровка: параметры фиксированы, меняется среда.
Предсказание модели — как поведёт себя агент с geom-калиброванными
параметрами в criterion-среде.

### p_reward и p_switch в сводке eLife

Столбцы p_reward и p_switch в EcksteinEtAl_eLife2022_ProbSwitch.csv —
**оценённые параметры авторской модели** (RL и Bayesian), не параметры
задачи. Истинный p_reward = 0.75 для всех (из методов статьи).
p_switch отражает оценённую вероятность переключения, а не назначенную.

### Критерии отбора участников

1. Минимум 100 проб.
2. Accuracy > 0.55 на стабильных блоках (выполнял задачу).

### Наблюдаемые

| Наблюдаемая | Сравнивается | Обоснование |
|-------------|:------------:|-------------|
| Win-stay rate | **да** | Калибровано |
| Lose-shift rate | **да** | Производная |
| Recovery speed | **да** | D29 |
| Mood | **нет** | Нет данных |
| Adaptive alpha | **нет** | Не воспроизводит |
| Confidence | **нет** | Модель не производит |

### Параметры

**131 проб < 500.** Ни один параметр не оценивается из данных. Сравнение
поведенческое, как для arousal: фиксируем всё, сравниваем наблюдаемые.

| Параметр | Класс | Действие |
|----------|-------|----------|
| beta | fitted (r=0.90 при N=500) | **Фиксирован: 2.50** (N=131 < 500) |
| alpha | fitted (условно) | **Фиксирован: 0.15** (N=131 < 1000) |
| tau_m | exploratory | Фиксирован: 2.163 |
| lambda | exploratory | Фиксирован: 0.49 |

**Несопоставимость параметров.** Авторские оценки (α=0.76, β=3.53)
получены на другом протоколе (criterion-based reversal, p_incorrect=0,
возраст 8–30) другим оценщиком. Наши (α=0.15, β=2.50) калиброваны на
Behrens/Rutledge. Разница — не расхождение модели с данными, а
несопоставимость параметров между контекстами. Eckstein et al. (eLife
2022) показали это эмпирически: «the interpretation of computational
model parameters depends on the context». Записывается как подтверждение
классификации восстановимости (правило 18), не как ошибка калибровки.

### Критерии согласия

Сравнение поведенческое (все параметры фиксированы):
1. **Win-stay (WS):** среднее модели попадает в IQR данных (взрослые 18+).
   Overlap coefficient распределений.
2. **Lose-shift (LS):** аналогично.
3. **Accuracy (ACC):** аналогично.
4. **Recovery speed:** медиана отношения модельной к эмпирической.

Отчёт: распределения рядом, не бинарный вердикт.

**Несопоставимость протоколов (ограничения):**
1. Наш протокол (Geom reversals, p_incorrect=0.25) ≠ Eckstein (criterion,
   p_incorrect=0). Сравнение показывает устойчивость модели к различиям.
2. 120 проб < 500. Параметры не оцениваются.
3. Возраст 8–30. Только взрослые (18+) для сравнения.
4. Авторские α/β несопоставимы с нашими (разный контекст, eLife 2022).

### Ограничения

- Возраст 8–30. Модуль калиброван на взрослых (Rutledge 2014).
  Сравнение со взрослой подвыборкой (18+).
- 131 проба < 500. Параметры не оцениваются из данных.
- Здоровые, нет клинических.
- lambda, tau_m exploratory. Фиксация обоснована.

## Порядок работы

1. **Шаг 0a:** скачать метаданные Confidence Database, посчитать
   выживаемость отбора. Доложить число наборов.
2. **Шаг 0b:** утвердить spec (после шага 0a, если число наборов >= 10).

## Стоп

Шаг 0a (проверка выживаемости) — до утверждения. К загрузке данных
не приступать до утверждения spec после шага 0a.
