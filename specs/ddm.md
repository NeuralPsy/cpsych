## Модель

Одномерный накопитель свидетельства с двумя поглощающими границами.
Каноническая DDM (Ratcliff 1978) без межпробной вариабельности параметров
(eta, sz, st). Стимул поступает от PerceptualTask (готова, P2.1).

### Уравнение

```
dx = v · dt + σ · dW,    σ = 1 (фиксировано для идентифицируемости)
v = kappa · coherence · direction
```

- coherence ∈ {0, 0.032, 0.064, 0.128, 0.256, 0.512} — из PerceptualTask.
- direction ∈ {-1, +1} — из PerceptualTask.
- Границы: ±a/2 (симметричные). |evidence| ≥ a/2 → проба завершена.
- Начальная точка: evidence = 0 (без смещения; эквивалентно z = a/2 в
  [0, a]-параметризации Ratcliff).
- choice = sign(evidence) при пересечении границы.
- correct = (choice == direction).
- RT = trial_clock + Ter.

**σ = 1** — стандартная конвенция DDM (Ratcliff & McKoon 2008, p. 883).
Один из параметров {v, a, σ} должен быть фиксирован для идентифицируемости;
фиксация σ — каноническая. Все остальные параметры — в относительных единицах.

**Аналитические формулы (Bogacz et al. 2006):**

Accuracy:
```
P(correct) = 1 / (1 + exp(-v · a))     [при σ=1, z=a/2]
```

Accuracy определяет произведение v·a, не v и a по отдельности. Разделение —
через RT (при одном v·a, бо́льший a → медленнее, та же accuracy).

**Процедура калибровки (замкнутая, без итераций):**

Обозначим p = κ·a.

**Шаг 1: p из accuracy.** P(correct|coh) = 1/(1+exp(−p·coh)). Единственный
свободный параметр p определяется логистическим MLE по 6 accuracy×coherence
точкам monkey N. Решение единственно (логарифм правдоподобия строго вогнут).

**Шаг 2: a из RT.** Безусловное среднее время решения при фиксированном p:

```
E[DT|coh] = a² · h(p, coh)

h(p, coh) = tanh(p·coh/2) / (2·p·coh)   для coh > 0
h(p, 0)   = 1/4                           (предел при coh → 0)
```

При фиксированном p, E[DT] ∝ a². Наблюдаемое:

```
mean_RT_i = a² · h(p, coh_i) + Ter       (i = 1..6)
```

Два неизвестных (a², Ter), шесть уравнений → OLS. Решение единственно.
κ = p/a.

**Шаг 3: Ter из LSQ-остатка.** Ter — свободный член регрессии из шага 2.

Все три параметра определены однозначно, без итераций, без свободных запасов
(правило 21). Если OLS-невязки систематически велики (нормированный RMSE > 15%
по любому уровню когерентности) — эскалация: базовая DDM может не подходить.

### Drift и diffusion

```python
def drift(x, theta, u):
    kappa = theta[:, 0:1]
    coherence = u[:, 0:1]   # из PerceptualTask через D15
    direction = u[:, 1:2]   # из PerceptualTask через D15
    v = kappa * coherence * direction
    return np.hstack([v, np.ones_like(v)])  # [evidence_drift, clock_drift=1]

def diffusion(x, theta):
    B = x.shape[0]
    sigma = 1.0  # fixed
    return np.hstack([np.full((B, 1), sigma), np.zeros((B, 1))])
    # [evidence_noise=1, clock_noise=0]
```

### Outputs

```python
def outputs(x, theta):
    evidence = x[:, 0]
    a = theta[:, 1]
    choice = np.where(evidence >= a / 2, 1.0,
                      np.where(evidence <= -a / 2, -1.0, 0.0))
    trial_clock = x[:, 1]
    Ter = theta[:, 2]
    rt = trial_clock + Ter  # осмысленно только при trial_done
    return {"evidence": evidence, "choice": choice, "rt": rt}
```

- `evidence`: текущее накопленное свидетельство (B,).
- `choice`: ±1 при пересечении границы, 0 во время накопления. Используется
  интегратором для `env.reward(action=choice)`.
- `rt`: trial_clock + Ter. Осмысленно только при trial_done = True.

### trial_done и reset_state (D14)

```python
def trial_done(x, theta):
    a = theta[:, 1]
    return np.abs(x[:, 0]) >= a / 2

def reset_state(x, theta, mask):
    x_new = x.copy()
    x_new[mask, 0] = 0.0  # evidence → 0 (= z, без смещения)
    x_new[mask, 1] = 0.0  # trial_clock → 0
    return x_new
```

trial_done нуждается в пороге a из theta. reset_state сбрасывает evidence в 0
и trial_clock в 0. Текущие сигнатуры базового класса (trial_done(x),
reset_state(x, mask)) не позволяют передать theta → **D14**.

### Temporality

EPISODIC — оба состояния сбрасываются при trial_done. Arousal не участвует
в trial loop (trial_done → always False); DDM — полностью эпизодический.

### Характерные масштабы

| Масштаб | Переменные | Значение |
|---------|-----------|----------|
| Trial duration | evidence, trial_clock | ~0.1–1.0 MTU (зависит от kappa, a, coherence) |
| Non-decision | — | Ter MTU (аддитивный сдвиг) |

При coherence=0: средний decision time = (a/2)² MTU (случайное блуждание).
При coherence=0.512: средний decision time ≈ (a/2) / (kappa·0.512) MTU.

Жёсткость с arousal: arousal timescale ~10 с (tau_m) vs DDM ~0.1–1 MTU.
Отношение зависит от калибровки MTU. В композите (P3): DDM в быстром тире,
arousal — в медленном.

### Тайм-аут пробы

**Экспериментальный контекст.** Задача Roitman & Shadlen 2002 — свободный
ответ (reaction time paradigm, без дедлайна). Обезьяна могла отвечать столько,
сколько нужно. Максимальные наблюдённые RT — порядка 2–3 с. Все пробы
завершались ответом.

**Тайм-аут в модели.** При coherence = 0 процесс — чистое случайное блуждание.
Среднее время выхода конечно ((a/2)²), но распределение тяжелохвостое:
P(DT > t) ~ exp(−π²t/(2(a/2)²)). На хвосте сетки параметров (большое a,
малое kappa) отдельные пробы могут быть вычислительно дорогими.

**T_max_trial** — максимальная длительность пробы в MTU. Численный
предохранитель, не свойство задачи (в данных тайм-аутов нет).

**Выбор T_max_trial.** Калибруется по **худшему узлу** сетки recovery
(минимальная κ, максимальное a, coherence = 0), а не по baseline. Критерий:
P(DT > T_max_trial) < 0.001 на худшем узле. На baseline пороговых значениях
доля будет на порядки меньше.

Для случайного блуждания с границами ±a/2, σ=1:
```
P(DT > t) ≈ (4/π) · exp(−π²t / (2·(a/2)²))
P(DT > t) < 0.001  ⟹  t > 2·(a/2)²/π² · ln(4000/π) ≈ 1.46·(a/2)²
```
С запасом: T_max_trial = 5·(a_max/2)², где a_max — верхняя граница a в
сетке recovery. Точное значение TBD после установления диапазона a.

**Обработка при срабатывании.** Проба помечается как **усечённая** и
**исключается** из всех наблюдаемых (accuracy, mean RT, квантили).
Доля усечённых проб записывается отдельно как диагностика.

- Если доля усечённых на каком-либо узле сетки recovery > 0.1% — узел
  помечается недостоверным. Его наблюдаемые не используются в оценке θ̂.
  Это входит в карту невозможного (параметры, при которых модель не может
  стабильно порождать ответы), а не размывается случайными подстановками.
- Если доля усечённых при baseline > 0 — T_max_trial недостаточен, увеличить.

**Обоснование исключения (не подстановки).** В данных Roitman & Shadlen
тайм-аутов нет — обезьяна всегда отвечала. Модель не должна порождать
тайм-ауты как наблюдаемую категорию. Подстановка (случайный выбор,
RT = T_max) смещает accuracy к 0.5 и mean RT вверх, сильнее всего при
нулевой когерентности — ровно там, где стоит цель «0.50 ± 0.05».
Смещение маскирует ошибку.

**Тест предохранителя.** Два условия:
1. Доля усечённых на худшем узле сетки < 0.001.
2. Статистики (accuracy, mean RT per coherence) при T_max и при 2·T_max
   совпадают в пределах шума (|Δ| < 2·SE). Второе условие важнее: оно
   показывает, что предохранитель не влияет на результат.

## Связи (P3, проектируем, не реализуем)

### arousal.gain → DDM.kappa

Механизм: мультипликативная модуляция чувствительности уровнем возбуждения.

```
kappa_eff = kappa_base · max(0, 1 + strength · (gain − 1))
```

- gain = 1.0 (baseline): kappa_eff = kappa_base. Нет модуляции.
- gain > 1.0 (повышенное): kappa_eff > kappa_base. Быстрее, лучше accuracy.
- gain < 1.0 (пониженное): kappa_eff < kappa_base. Медленнее, хуже accuracy.
- gain ≈ 0.02 (сон): kappa_eff = kappa_base · max(0, 1 − 0.98s). При s ≥ 1.02
  clamp → 0, проба не завершается (D10, гейтирование циклом проб).

**Почему мультипликативная.** Аддитивная формула kappa_base + s·(gain−1) меняет
знак κ при s > kappa_base/(1−gain_min). При gain_min = 0.79 (нижний край
trimmed wake): s > 4.76·kappa_base → κ < 0, что означает систематически
неверные ответы, а не замедленные. Мультипликативная форма сохраняет знак
(kappa_eff ≥ 0 всегда) и безразмерна (gain — отношение к базовой линии).

**Допустимый диапазон strength.**

Условие: kappa_eff > 0 во время бодрствования (gain ∈ [0.79, 1.05]):
```
1 + s · (gain_min − 1) > 0
1 − 0.21s > 0
s < 4.76
```

Диапазон ручки strength: [0, 4.0] (с запасом ~16% от порога переворота).
При strength = 1: kappa_eff = kappa_base · gain (простое масштабирование).
При strength = 4: kappa_eff ∈ [0.16, 1.20] · kappa_base (сильная модуляция).

Критическая сила связи для устойчивости композита — P3 (правило 19), может
дополнительно ограничить сверху.

Реализация через Coupling (P1) с кастомным h:
```python
Coupling(
    source_module="arousal", source_output="gain",
    target_module="ddm", target_param="kappa",
    strength=TBD,
    h=lambda gain, kappa_base: kappa_base * np.maximum(0, 1 + strength * (gain - 1)) - kappa_base,
    # modulate(theta, idx, src) adds h(src) to theta[idx], so h returns delta
)
```

Примечание: Coupling.modulate добавляет h(src) к theta_base[idx]. Для
мультипликативной связи h возвращает дельту: kappa_eff − kappa_base.

## Parameter recovery

### Процедура

Сетка: kappa × a × Ter = 5³ = 125 точек × 20 реплик.
Каждая реплика: **~2800 проб** (6 когерентностей × ~470 на уровень), что
соответствует числу проб monkey N в RT-задаче (~2858 проб). Точное число
уточняется после загрузки данных.

**Обоснование числа проб.** SE accuracy при 200 пробах (33 на уровень):
sqrt(0.25/33) ≈ 0.087 — сопоставимо с разницей между узлами сетки, recovery
неинформативен. При ~470 на уровень: SE ≈ 0.023 — достаточно для разрешения
сетки 5 значений. Результат recovery говорит о восстановимости параметров
на том же числе проб, что и в реальных данных.

**Наблюдаемые** (на реплику):
- Per-coherence accuracy: 6 значений.
- Per-coherence mean RT (все ответы, не только correct): 6 значений.
- Итого: 12 наблюдаемых.

**Метод:** grid search по расстоянию между предсказанными и наблюдёнными
(стандартизованный L2).

### Вычислительная стоимость

B = 125 × 20 = 2500 реплик. Средняя длительность пробы ~500 шагов при dt=0.001.
2800 проб × 500 шагов × 2500 батч × 2 состояния ≈ 7B float ops.
Оценка: ~5 мин CPU (numpy vectorized). Приемлемо.

### Порог

- **fitted** если r(θ, θ̂) ≥ 0.7 И |кросс-корреляция| < 0.6 с другими.
- **exploratory** если r < 0.7 (правило 18).

### Ожидаемые сложности

1. **kappa и a спутаны через accuracy.** P(correct) зависит от произведения
   kappa·a. Разделение — через RT: при одном kappa·a, больший a → медленнее
   (аккуратнее), та же accuracy. 12 наблюдаемых (6 accuracy + 6 RT) должны
   разделить.

2. **Ter ортогонален.** Сдвигает всё распределение RT, не влияет на accuracy
   и decision time. Восстановимость ожидается высокая.

3. **DDM проще arousal.** Три свободных параметра, аналитические формулы.
   Recovery ожидается лучше, чем для flip-flop (r=0.05–0.41).

## Отложенные наблюдаемые

Объявлены до реализации (правило 17). Не используются при настройке.
Проверка — однократная, в конце P2.3.

1. **Квантили RT** (Q10, Q30, Q50, Q70, Q90) per coherence — форма
   распределения RT. DDM предсказывает правостороннюю асимметрию,
   зависящую от drift rate. Сравнение с данными monkey N.

2. **Right-skew:** Q90/Q50 per coherence — безразмерное свойство формы,
   инвариантное к масштабу и сдвигу. Паттерн right-skew vs coherence
   фиксирован для данного набора {kappa, a}; данные monkey N.

3. **Равенство RT-распределений правильных и ошибочных ответов.**
   Каноническая DDM без межпробной вариабельности (eta=0, sz=0, st=0)
   предсказывает, что RT правильных и ошибочных ответов имеют одинаковое
   распределение при каждом уровне когерентности. Это **положительное
   предсказание** базовой модели.

   Проверка: |Cohen d(RT_correct, RT_error)| < 0.1 per coherence (D17).
   Исходный критерий KS p>0.05 заменён: при N≈5000 KS ловит шум
   уровня d=0.04, что не является содержательным расхождением.

   **Отчётная величина (не критерий):** сравнение с данными monkey N.
   Если у обезьяны ошибки при высокой когерентности (≥ 25.6%) систематически
   медленнее правильных (slow errors) — это документирует потребность в
   межпробной вариабельности eta (Ratcliff & McKoon 2008, Section 4) и
   служит обоснованием для будущего расширения. Но остаётся наблюдением,
   а не критерием прохождения: базовая DDM не воспроизводит slow errors
   по построению.

## Held-out (D8)

**Monkey B — cross-subject.** Настройка на monkey N. Однократная проверка
на monkey B:

- Accuracy per coherence: |model − data| ≤ 0.10 по каждому уровню.
- Mean correct RT per coherence: |model − data| / data ≤ 0.25 по каждому уровню.

Однократно. Если held-out провален — это результат, настройка не
возобновляется (правило 17).

## Цели настройки

Настройка по данным monkey N из Roitman & Shadlen (2002):

1. **Психометрическая кривая:** accuracy по 6 когерентностям monkey N,
   ошибка ≤ 0.05 на каждом уровне.
2. **Хронометрическая кривая:** mean correct RT по 6 когерентностям
   monkey N, ошибка ≤ 15% на каждом уровне.
3. **Chance at zero coherence:** accuracy при 0% когерентности = 0.50 ± 0.05.
4. **Монотонность RT:** mean correct RT убывает с когерентностью.

Критерий успеха: все 4 цели выполнены при калиброванных параметрах.

## Критерий провала

- Доля усечённых проб при baseline > 0 (предохранитель T_max недостаточен).
- Accuracy при 0% когерентности ≠ 0.50 ± 0.05.
- RT не убывает с когерентностью (нарушение монотонности при coh > 0).
- Невязки калибровки: нормированный RMSE > 15% по любому уровню когерентности.
- Ни один параметр r ≥ 0.7 при parameter recovery → эскалация.

(results/ddm_resolution.json).

|----------|----------------|-------|-----------------|
| kappa | 0.44 | 3.0% | 0.5 |

**Асимметрия a.** Аналитический сигнал симметричен (L2 ratio 1.02), но
стохастический шум несимметричен: при a−3% accuracy дальше от потолка (больше
ошибок → бо́льшая биномиальная дисперсия) и RT короче (то же аддитивное σ —
бо́льшая относительная ошибка). В результате наблюдаемые при a−3% шумнее и
хуже отличимы от baseline. Не артефакт сетки (baseline в центре). Свойство
DDM: ручка a имеет асимметричное разрешение. В песочнице шаг a вниз должен
быть крупнее (0.10), чем вверх (0.05).

## Наблюдаемые, которые модуль не воспроизводит

Каноническая DDM (без eta, sz, st) не воспроизводит:

1. **Квантильный профиль RT.** Q90 завышен на 23–34% при coh ≤ 0.064.
   Q10 занижен на 10–35% при высоких coh. Модель слишком
   тяжелохвостая при низких когерентностях, слишком сдвинута при высоких.

2. **Паттерн right-skew vs coherence.** Модель: Q90/Q50 убывает с
   когерентностью (2.00 → 1.16). Данные: слабо зависят (1.30 → 1.59).
   Качественное расхождение.

3. **Slow errors.** Данные monkey N: ошибки на 66–201 мс медленнее
   правильных при coh ≥ 0.032. Модель: RT correct ≡ RT error (по
   построению, без eta).

**Правило для P4:** карта невозможного по этим наблюдаемым не строится;
если строится — помечается как недостоверная. Известный дефект модели
не должен молча стать областью на карте.

**Причина:** отсутствие межпробной вариабельности drift rate (eta).
DDMExtended (D16) заводится как отдельный модуль для воспроизведения
формы RT. До его реализации перечисленные наблюдаемые не используются
как цели или ограничения.

## Оговорки

1. **Данные обезьян, не людей (D8).** Параметры DDM обезьян отличаются от
   человеческих. Функциональная валидация (паттерн RT × accuracy × coherence)
   переносима между видами; абсолютные значения параметров — нет. При появлении
   человеческих trial-level данных — замена roitman_rts.csv без изменения кода.

2. **σ = 1 — все параметры в относительных единицах.** kappa, a, Ter имеют
   смысл только относительно σ. При фиксации σ = 0.1 (альтернативная конвенция)
   числовые значения масштабируются в 10 раз.

3. **Нет межпробной вариабельности (eta, sz, st).** Базовая DDM не включает:
   - eta: вариабельность drift rate между пробами,
   - sz: вариабельность начальной точки,
   - st: вариабельность non-decision time.
   Эти параметры нужны для slow errors (Ratcliff & McKoon 2008, Section 4).
   Если отложенная #3 (slow errors) провалится — эскалация к автору,
   не автоматическое добавление параметров задним числом.

4. **Время в MTU, не в секундах.** Пересчёт в секунды: из калибровки Ter к
   экспериментальному floor RT (Roitman & Shadlen: ~200 ms для monkey N).
   Внутри модели — безразмерное.

## Решения, требующие утверждения

### D14: Расширение контракта trial_done и reset_state

DDM нуждается в theta внутри trial_done (порог a) и reset_state (начальная
точка z = 0, но в принципе может зависеть от theta). Текущие сигнатуры
базового класса:
```python
trial_done(x) -> np.ndarray[bool]
reset_state(x, mask) -> np.ndarray
```

**Предлагается:**
```python
trial_done(x, theta) -> np.ndarray[bool]
reset_state(x, theta, mask) -> np.ndarray
```

Base class defaults игнорируют theta — обратная совместимость:
```python
def trial_done(self, x, theta):  # base: ignores theta
    return np.zeros(x.shape[0], dtype=bool)

def reset_state(self, x, theta, mask):  # base: ignores theta
    x_new = x.copy()
    for i, sv in enumerate(self.spec.states):
        if sv.temporality == Temporality.EPISODIC:
            x_new[mask, i] = sv.initial
    return x_new
```

**Затрагивает:**
- `module.py`: сигнатуры trial_done, reset_state (base class).
- `integrator.py`: 2 call sites в `_handle_trials`:
  - `mod.trial_done(state.x[mod_name])` → `mod.trial_done(state.x[mod_name], theta_eff)`
  - `mod.reset_state(state.x[mod_name], done)` → `mod.reset_state(state.x[mod_name], theta_eff, done)`
- `conftest.py`: ToyDDM.trial_done — обновить сигнатуру. Можно использовать
  threshold из theta вместо хардкода 1.0.
- `test_module.py`: тесты trial_done и reset_state — обновить вызовы.
- ArousalModule: **не затронут** (trial_done → always False, reset_state →
  default; оба игнорируют theta).

**Альтернатива (отвергнута):** хранить threshold в объекте модуля (не в theta).
Нарушает правило 20 (чистые функции) и batch-ось (у разных реплик может быть
разный порог при parameter sweep).

### D15: Интегратор передаёт стимул как u

DDM drift зависит от coherence и direction из среды. DDM объявляет
`input_names = ("coherence", "direction")`. Интегратор должен заполнять
u из текущего стимула среды.

**Предлагается:** в `_step_module`, если стимул доступен и модуль объявляет
input_names, заполнять `u[:, i]` из `stimulus[input_name]`:

```python
def _step_module(self, name, dt, state, stimulus=None):
    mod = self.modules[name]
    x = state.x[name]
    theta = self._effective_theta(name, state)
    u = np.zeros((self.B, mod.n_inputs))
    if stimulus and mod.spec.input_names:
        for i, inp in enumerate(mod.spec.input_names):
            if inp in stimulus:
                u[:, i] = stimulus[inp]
    dx = mod.drift(x, theta, u)
    ...
```

**Затрагивает:**
- `integrator.py`: `_step_module` (~5 строк), `_run_tier` и `run` (передают
  stimulus в `_step_module`).
- Текущее поведение (`u = zeros`) сохраняется для модулей без input_names в
  stimulus или без среды.
