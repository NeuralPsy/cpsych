# P5 Спецификация: песочница (v3)

## Назначение

Интерактивный интерфейс к платформе: пользователь крутит параметры модулей
и силы связей, видит наблюдаемые и предупреждения. Не оптимизатор, не
подгонщик. Инструмент «что если»: показывает, что модель производит и от
чего отказывается.

## Что показываем

### 1. Ручки (параметры)

Три визуально различимых класса (правило 18):

| Класс | Визуал | Смысл |
|-------|--------|-------|
| **Fitted** (r >= 0.7) | основной цвет | Восстановим из данных |
| **Exploratory** (recovery < 0.7) | приглушённый + пометка | Крутить можно, оценить нельзя |
| **Untested** (recovery не проводился) | пунктирная рамка | Статус неизвестен |

#### Fitted параметры с разрешением

| Параметр | Калибр. | MDD (80%) | Шаг ручки | Примечание |
|----------|--------:|----------:|----------:|------------|
| kappa (DDM) | 14.724 | 0.44 (3.0%) | 0.5 | N=3500, standalone |
| a (DDM) | 1.492 | 0.045 (3.0%) | 0.05 вверх, 0.10 вниз | Асимметричное |
| Ter (DDM) | 0.318 | 0.010 (3.0%) | 0.01 | -- |
| beta (RL) | 2.50 | 0.40 (16%) | 0.4 | N=500, standalone |
| alpha (RL) | 0.15 | 0.06 (40%) | 0.06 | N=500, standalone. См. ниже |

Шаг ручки = MDD: вращение на меньшую величину не порождает различимого
эффекта. beta и alpha имеют MDD грубее DDM (16% и 40% vs 3%).

#### Класс alpha зависит от длины наблюдения

r(alpha) = 0.67 при N=500 (exploratory), 0.77 при N>=1000 (fitted).

| coherence | Проб на окно (600 с) | N за 5 окон | Класс alpha |
|-----------|---------------------:|------------:|-------------|
| 0.128 | ~1650 | ~8300 | fitted |
| 0.064 | ~1190 | ~6000 | fitted |
| 0.032 | ~1070 | ~5300 | fitted (маргинально) |

В интерфейсе: alpha отображается с пояснением «fitted при >=1000 проб;
при текущей конфигурации ~N проб». При N < 1000 -- класс exploratory.

#### Coupling strengths

| Связь | Ручка | Диапазон | Зоны |
|-------|-------|----------|------|
| gain -> kappa | s_kappa | [0, 4] | -- |
| gain -> alpha | s_alpha | [0, 4] | -- |

s_value: два показателя (accuracy opt ~3, recovery degrades from ~2).

### 2. Наблюдаемые

#### Поведенческие (из trial loop)

accuracy, mean_rt, win_stay_rate, trial_count.
Per-window разбивка при полном прогоне.

#### BAA (отдельная панель)

total_activation, energy, attention_entropy. Пометка: пассивен (D42).

### 3. Карта невозможного

Предрассчитанные JSON из P4. Семь типов областей:
NORMAL, INDISTINGUISHABLE, CHANCE, UNSTABLE,
NO_DATA_GATE, NO_DATA_KAPPA, NO_DATA_TIMEOUT.

Текущие ручки -- точка на карте.

### 4. Предупреждения (не запреты)

lambda > lambda_crit, v_vh за окном, s_value > 10, boundary > 10%, BAA пассивен.

## Каскад отклика

### Замеры (2026-08-04, после структурного выноса slow-tier outputs)

| Конфигурация | Стена |
|---|---:|
| 1 окно, B=1 | 44.6 с |
| 1 окно, B=30 | 56.5 с |
| 5 окон, B=30 | **4.5 мин** |

Структурный вынос: outputs slow-tier модулей вычисляются один раз за
медленный шаг и передаются в быстрый тир готовыми значениями. Lie-Trotter
инвариант: slow state постоянен на быстром интервале. Ускорение 2.8x
(было 12.5 мин -> 4.5 мин).

Амортизация работает: B=30 стоит 56.5 с (1.9 с/реплику vs 44.6 с при B=1).
30 реплик для prediction interval почти бесплатны.

### Два уровня

**1. Мгновенный (< 100 мс).** Аналитические формулы DDM.
- accuracy = 1/(1+exp(-kappa*a*coh)). mean_RT = a^2*tanh()/() + Ter.
- lambda_crit, position on map, warnings, alpha class.
- Помечено: **"DDM без связей, идеализация"**.
- Формулы не учитывают: coupling, gain modulation, reversals, mood.
  Совпадают с прогоном только при всех выключенных связях.

**2. По кнопке (~4.5 мин).** Полный стохастический прогон.
- B=30 реплик, 5 окон x 600 с. Prediction interval (SD по репликам).
- После прогона: аналитика и прогон рядом (не подмена).
- Расхождение при default couplings: аналитика 0.943, прогон 0.955 (+1.2%).

### CI -- prediction interval, не SEM

Интервал = mean +/- 1.96*SD (разброс между репликами). Показывает, что
получится при одном прогоне, а не среднее по бесконечному числу прогонов.
Ширина ~0.009 по accuracy (сопоставима с MDD kappa = 3%).

## Критерий P5 gate

1. Каждый fitted параметр имеет ручку с шагом = MDD.
2. Exploratory визуально отличимы. alpha -- динамический класс.
3. Предупреждения срабатывают.
4. Аналитика < 100 мс. Прогон ~4.5 мин по кнопке.
5. Карта невозможного с текущей позицией ручек.
6. BAA помечен как пассивный.
